# 👋 Bem-vindo à Wiki

Esse site reúne receitas, guias técnicos e tudo mais que for útil para o dia a dia.

## Como adicionar um novo item

Quer contribuir? Ótimo! Siga os passos abaixo.

### 1. Abra um Pull Request

Todo conteúdo novo entra via PR no repositório:

👉 [github.com/jorgebinho/docusaurs-test](https://github.com/jorgebinho/docusaurs-test)

Crie uma branch com um nome descritivo, adicione seu arquivo e abra o PR para revisão.

### 2. Crie o arquivo `.mdx`

Os arquivos ficam dentro da pasta `docs/`, organizados por categoria:

### 3. Estrutura básica de um arquivo `.mdx`

Todo arquivo precisa começar com um frontmatter (as linhas entre ---):

O frontmatter tem essa cara:

sidebar_position: 1

Onde sidebar_position define a ordem no menu lateral. Depois disso é Markdown normal.

### 4. Recursos disponíveis

Além do Markdown padrão, você pode usar admonitions e tabs.

:::tip Dica
Texto da dica aqui.
:::

:::info Informação
Texto informativo aqui.
:::

:::warning Atenção
Texto de aviso aqui.
:::

import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

<Tabs>
  <TabItem value="mac" label="macOS" default>
    Instruções para macOS aqui.
  </TabItem>
  <TabItem value="windows" label="Windows">
    Instruções para Windows aqui.
  </TabItem>
</Tabs>
